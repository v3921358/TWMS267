### How to Run the Game

1. Rename the original `machineidlib` file in the official client folder to `machineidlib_old`.
2. Copy the **modified** `machineidlib` into the same folder.
3. Set your PC's system locale to **Taiwan** (or use a **locale emulator** like [Locale Emulator](https://xupefei.github.io/Locale-Emulator/)).
